# UniFlow

UniFlow - Telegram-бот, который помогает сохранять учебные задания и дедлайны, планировать работу и не забывать о сроках. В нём можно добавлять и редактировать задачи, смотреть план на день и получать напоминания.

В проект добавлена интеграция с GigaChat для разбора текста заданий и объяснения плана. Перед сохранением бот предлагает проверить найденные задачи и даты. Без подключения ИИ доступен локальный разбор.

В боте предусмотрены корректные отказы на недопустимые действия пользователя. Например, бот отклоняет неверные данные, устаревшие кнопки, повторные подтверждения и попытки изменить чужую, удалённую или уже завершённую задачу.

При разработке я использовал OpenAI для помощи в написании некоторых участков кода. Часть сценариев работы бота проверял вручную; также в проекте есть автоматические тесты.

Бот написан на PHP 7.4+, использует вебхук Telegram и базу SQLite.
