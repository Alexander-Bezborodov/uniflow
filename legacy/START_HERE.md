# Запуск UniFlow

В архиве исходники, тесты и документация. Рабочие ключи и пользовательская база не включены.

1. Установи Python 3.12-3.14 и создай виртуальное окружение по README.md.
2. Установи зависимости: `python -m pip install -r requirements.txt`.
3. Скопируй `.env.example` в `.env`, укажи токен своего бота в `BOT_TOKEN` и выбери свой `TIMEZONE`.
4. Проверь конфигурацию: `python main.py --check`.
5. Запусти: `python main.py`.

Пустая база и папка data создадутся автоматически при запуске.
ИИ необязателен; при необходимости укажи собственный ключ в LLM_API_KEY.
Подробные команды для macOS и Windows находятся в README.md.
