# UniFlow: аудит и исправления

Дата: 05.09.2026. Основа - папка `uniflow` из предоставленного `top.zip`.
Выполнена актуальная задача из PROMPT.md: обычный Telegram-бот сохранён.
Mini App, сайт, HTTP API приложения и платёжные функции не создавались.

## Исходная проверка и воспроизведение

Исходные 109 тестов фактически запущены на Python 3.14.0: 109 passed.
Затем на исходной реализации добавлены регрессии: сохранение настроек, изоляция дат
разных задач, истечение срока во время ручной формы. Все три теста сначала упали.
Контрольный тест одного UTC-момента и двух локальных дат прошёл.

Скриншот изучен: заголовок 6 сентября / Asia/Yekaterinburg, календарные строки без
слова «Дедлайн». Время съёмки и ожидаемый пояс неизвестны. Ошибка системных часов
**не подтверждена**, сутки вручную не вычитались.

## Что сохранено и проверено повторно

Сохранены aiogram 3.x, SQLite/aiosqlite, long polling, главный сценарий, исходные команды,
добавлены /settings, /ai, /explain и соответствующие кнопки. Алгоритм приоритетов и модель
статистики не переписаны; проверены исходными и новыми тестами. Демонстрационные данные
остаются только пользовательскими, реальные задачи после /demo сохраняются.

Изменённые ожидания старых тестов обоснованы поведением: 334 вместо лимита 180;
«завтра» из исходного текста вместо выдуманной моделью даты; harness учитывает EditMessageText
при проверке новой пагинации. Тесты на ошибки не удалялись ради зелёного результата.

Финальные результаты команд и точный счётчик тестов - в [VERIFICATION.md](VERIFICATION.md).

## Границы проверки

- Все Telegram-вызовы в автотестах подменены. Настоящий polling, реальные доставки и визуальный
  просмотр нового UI в Telegram не проверены: токен своего тестового бота не предоставлялся.
- HTTP-клиент aiohttp проверен по TCP с поддельным сервером на 127.0.0.1. Это не Groq.
- Реальный ключ, доступ региона/аккаунта, настоящие ответы обеих AI-функций не проверены.
  Команда --check-llm и ручные шаги даны в README; fallback не считается успешным API-вызовом.
- Windows и Linux не запускались. Python 3.12/3.14 проверены на macOS ARM64.
- Напоминания не имеют exactly-once между Telegram и SQLite; возможный аварийный повтор
  выбран и проверен явно. Локальная блокировка процесса не защищает от запуска на другой машине.
- Журнала отработанных минут нет по согласованной простой модели. Нет обещания полного отсутствия
  неизвестных ошибок или универсального понимания любого текста преподавателя.
