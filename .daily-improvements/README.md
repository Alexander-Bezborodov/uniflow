# План ежедневных улучшений

Каталог содержит 30 заранее подготовленных дневных версий. Фоновый запускатель в родительском каталоге применяет по одному файлу плана в соответствующую дату.

Каждый план добавляет одну небольшую полезную запись в каждый из десяти файлов каталога `docs/improvement-log`.
